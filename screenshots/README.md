# Screenshots

Drop QA screenshots, device captures, and bug-report attachments here.

Claude reads files from this folder when you reference them in conversation
(e.g. "look at `screenshots/preview-bug.png`"). The folder exists in version
control via this README, but the screenshot files themselves are intentionally
left for you to add or `.gitignore` per your preference — they're binary and
generally don't belong in repo history unless they're long-lived references
(e.g. issue reproductions you want preserved).

Suggested naming: `<topic>-<date>.png` — e.g. `preview-rendering-bug-2026-05-13.png`.
