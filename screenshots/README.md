# Screenshots

Map of this folder. Three things live here:

| Folder | What it is | Used for |
|---|---|---|
| **`v2.0/`** | Current release asset bundle — the Launch Kit Studio "Export All" for v2.0 | Play Console upload • your website / portfolio • social cards • brand tokens |
| **`showcase/`** | 12 raw device captures of v2.0 (palettes, scientific, tools, history, settings, Arabic) | ⚠️ **Embedded in the repo's top-level `README.md` image grid — do not move or rename these without updating the README links** |
| **`archive/`** | Superseded assets from past releases, parked not deleted | Reference only ("what did the listing look like at v1.3?") |

It's also a **drop-zone for ad-hoc QA captures / bug-report attachments** — Claude reads files here when you reference them in conversation (e.g. "look at `screenshots/preview-bug.png`"). Suggested naming for those: `<topic>-<date>.png`.

## `v2.0/` — current release bundle

Generated by Launch Kit Studio (`Sifr/ → Export All`), both locales (English + Arabic) in every category. Each subfolder carries its own `README.md` with per-file labels, headlines, and descriptions.

```
v2.0/
├── app-icon.png                         source app icon (square PNG)
├── android/{en,ar}/                     Play phone screenshots — 7 per locale, 1080×1920
├── marketing/{en,ar}/
│   ├── feature-graphic/                 Play feature graphic candidates — 1024×500
│   ├── portfolio-android/               website / portfolio renders — 1600×900
│   └── social/                          OG / X / LinkedIn / Bluesky cards — 1200×630
├── brand/                               design tokens — CSS vars, Tailwind theme, Style Dictionary JSON
└── README.md                            bundle manifest
```

**For Play Console:** upload `android/en/` (7 shots) under the English listing and `android/ar/` (7 shots) under Arabic; pick one `feature-graphic/` layout for the 1024×500 slot. Edit the **Default** store listing for en-US and **Manage translations** for Arabic — not "custom store listings."

**For the website / portfolio:** `marketing/{en,ar}/portfolio-android/` and `social/` are a selection library — multiple layout variants per locale; use whichever fit. `brand/` gives you matching colors/type for the page.

## `archive/`

- **`archive/v1.3-pre-redesign/`** — the old pre-redesign Play set (20 `Marketing — *.png` Compose exports + numbered `EN/`/`AR/` upload folders + that release's README with its 8-slot ordering + Play-tag scheme). Superseded by `v2.0/`; kept for reference.

## Next release (the workflow)

When a future version ships a new Launch Kit export:

1. Move the current `v2.0/` into `archive/v2.0/`.
2. Drop the new export in and rename its `sifr-all-<timestamp>/` folder to `v2.1/` (etc.).
3. Refresh `showcase/` if the UI changed (and the repo README will pick up the new captures automatically, since the filenames are stable).
