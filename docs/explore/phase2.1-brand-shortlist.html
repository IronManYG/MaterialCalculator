Phase 2.1 — Brand Shortlist

Four Arabic-rooted candidates for the namespace rename. The decision is creative-then-technical: pick a name, then everything else (namespace, app label EN/AR, marketing copy) follows mechanically.

In scope (Phase 2.1)

  • Kotlin namespace (com.example.materialcalculator → dev.gaddal.<brand>)
  • User-visible app label (English + Arabic via values-ar/)
  • Package directory tree under app/src/*/java/
  • All import com.example.materialcalculator... rewrites
  • Constants.kt source-set duplicates (debug/staging/release)

Out of scope

  • applicationId — STAYS com.gaddal.materialcalculator (preserves Play listing)
  • Logo redesign (separate effort)
  • Play Store screenshots (regenerated in Phase 2.6)
  • Play Store listing copy (separate marketing pass)
  • Domain registration / website

Cross-cutting notes

  • Namespace pattern: All four use the simple form dev.gaddal.<brand>. A nested form like dev.gaddal.calculator.<brand> would be over-engineered for a single-app project — added depth costs grep-ability without benefit.
  • App-label localization: Default app_name in res/values/strings.xml uses the Latin transliteration. res/values-ar/strings.xml uses the Arabic script. Android automatically picks based on device locale.
  • What does NOT change: applicationId stays com.gaddal.materialcalculator — Play Store URL, install base, ratings all preserved. Anyone who already has the app installed will see the new label after the next update; the package on disk stays the same.
  • Logo: Each brand suggests a different visual language. Raqam → numerals; Sifr → circular/zero motifs; Jabr → manuscript/historical aesthetic; Hasib → professional/abacus. Logo design is a separate effort once the name lands.
  • Trademark / search check: Before locking, the chosen name should be searched on Play Store, App Store, and Google for collisions. Quick test, must happen before the spec is final.
  • Domain availability: If a marketing site is in the long-term plan, check <brand>.app, get<brand>.app, <brand>calc.com at decision time. Out of Phase 2.1 scope but worth knowing if the chosen name has an obvious blocker.
