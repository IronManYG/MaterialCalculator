5 · Implementation phasing

  1. Build modernizationGroovy → KTS, version catalog, Gradle 9 + AGP 9, declarative JDK toolchain, local.properties footgun fix. Mechanical, no behavior change.
  2. Namespace renamecom.example.materialcalculator → dev.gaddal.<brand>. Brand decision lands here. Single mechanical pass.
  3. Architecture migrationReorganize into core/ + feature/calculator/. Introduce MVI, Koin, Navigation 3. ViewModelTests added.
  4. Settings featureDataStore + Settings screen + theme/haptics/sound toggles. MainActivity reads themeMode for AppTheme.
  5. History featureRoom + History screen + cross-feature seam (Calculator writes, History reads). Tap-to-restore via Nav3 saved-state.
  6. Error typing + i18nReplace "Error" sentinel with Result<Double, CalcError> + UiText + values-ar/.
  7. GitHub Actions CI + logo + screenshotsDeferred to a separate spec.
