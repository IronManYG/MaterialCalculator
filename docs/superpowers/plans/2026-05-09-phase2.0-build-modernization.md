# Phase 2.0 — Build Modernization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate MaterialCalculator's build to Kotlin DSL + Gradle version catalog + Gradle 9.4.1 + AGP 9.2.0 + declarative JDK 21 toolchain, with no behavior change.

**Architecture:** Two-stage migration. Stage 1 (Tasks 2–7): mechanical conversion of Groovy `.gradle` scripts to Kotlin DSL `.kts`, introducing `gradle/libs.versions.toml` as the single source of truth for dependency and plugin versions, while keeping AGP and Gradle versions UNCHANGED. Stage 2 (Tasks 8–11): bump Gradle wrapper to 9.4.1, add declarative JDK 21 toolchain via `gradle-daemon-jvm.properties`, bump AGP to 9.2.0 (drops the explicit `kotlin-android` plugin — AGP 9 ships built-in Kotlin support), wrap `local.properties` read in `runCatching` so non-release builds don't fail on missing keystore. Verify checkpoints between stages so a regression at any point can roll back to the prior commit.

**Tech Stack:** Kotlin DSL, Gradle version catalog (TOML), Gradle 9.4.1, AGP 9.2.0, foojay-resolver-convention 1.0.0, JDK 21, Kotlin 2.3.10, Compose BOM 2026.05.00, Material3 1.4.0.

**Branch:** `feature/phase2.0-build-modernization` (off `feature/phase2-greenfield-spec`, so spec/plan + execution land in one PR to `development`).

        applicationId = "com.gaddal.materialcalculator"
        minSdk = 24
        targetSdk = 36

            storeFile = file(keystoreProperties["keystore.file"] as String)
            storePassword = keystoreProperties["keystore.password"] as String
            keyAlias = keystoreProperties["keystore.alias"] as String
            keyPassword = keystoreProperties["keystore.alias_password"] as String

    testImplementation(libs.junit)
    testImplementation(libs.androidx.test.core)
    testImplementation(libs.androidx.arch.core.testing)
    testImplementation(libs.google.truth)

    androidTestImplementation(libs.androidx.test.ext.junit)

- Modify: `build.gradle.kts`
- Modify: `app/build.gradle.kts`

1. **Built-in Kotlin support** — the `org.jetbrains.kotlin.android` plugin is no longer needed and conflicts with AGP 9's built-in Kotlin compiler. Drop the plugin.

## Task 11: Fix `local.properties` footgun

**Files:**
- Modify: `app/build.gradle.kts`

Currently `app/build.gradle.kts:7` does `FileInputStream(keystorePropertiesFile)` unconditionally — every Gradle invocation fails if `local.properties` is missing or malformed, even `:app:assembleDebug`. Documented in CLAUDE.md as a known footgun.

The fix: wrap the read in `runCatching` and let signing config tolerate null values for non-release builds.

- [ ] **Step 1: Update the keystore properties read**

Edit `app/build.gradle.kts`. Replace the keystoreProperties initialization:

```kotlin
// Before:
val keystorePropertiesFile = rootProject.file("local.properties")
val keystoreProperties = Properties().apply {
    load(FileInputStream(keystorePropertiesFile))
}

// After:
val keystorePropertiesFile = rootProject.file("local.properties")
val keystoreProperties = Properties().apply {
    runCatching {
        FileInputStream(keystorePropertiesFile).use { load(it) }
    }
}
```

- [ ] **Step 2: Update the signing config to tolerate nulls**

Edit `app/build.gradle.kts`. Replace the signingConfigs block:

```kotlin
// Before:
signingConfigs {
    create("release") {
        storeFile = file(keystoreProperties["keystore.file"] as String)
        storePassword = keystoreProperties["keystore.password"] as String
        keyAlias = keystoreProperties["keystore.alias"] as String
        keyPassword = keystoreProperties["keystore.alias_password"] as String
    }
}

// After:
signingConfigs {
    create("release") {
        val storeFilePath = keystoreProperties["keystore.file"] as? String
        if (storeFilePath != null) {
            storeFile = file(storeFilePath)
            storePassword = keystoreProperties["keystore.password"] as? String
            keyAlias = keystoreProperties["keystore.alias"] as? String
            keyPassword = keystoreProperties["keystore.alias_password"] as? String
        }
        // If null, this signing config remains unconfigured.
        // Release builds will fail (correct: cannot sign without a key).
        // Debug builds use the default debug signing config.
    }
}
```
