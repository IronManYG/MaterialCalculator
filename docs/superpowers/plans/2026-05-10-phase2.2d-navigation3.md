# Phase 2.2d — Navigation 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task.

**Goal:** Insert Navigation 3 between `MainActivity` and `CalculatorRoot`. Add `Routes.kt` (single `data object CalculatorRoute : NavKey`), add `NavRoot.kt` (with `NavDisplay` + `entryProvider` DSL), wire `MainActivity` to call `NavRoot()`. Calculator is the only destination — Nav3 is in place ready for Phase 2.3 to add `SettingsRoute`.

**Parent spec:** `docs/superpowers/specs/2026-05-10-phase2.2d-navigation3.md` (full design rationale, including why kotlinx-serialization + `rememberNavBackStack` and `koin-compose-navigation3` are deferred).

**Architecture:** Three-stage refactor with atomic commits.
- **Stage A (Task 2):** Add Nav3 1.1.1 (runtime + ui) to the catalog and `app/build.gradle.kts`. Pre-flight.
- **Stage B (Task 3):** Create `navigation/Routes.kt` and `navigation/NavRoot.kt`. `NavRoot` is unreferenced until Task 4 — but it compiles green because all of its imports come from production deps now on the classpath.
- **Stage C (Task 4):** `MainActivity` calls `NavRoot()` instead of `CalculatorRoot()`. Nav3 is now load-bearing.
- **Stage D (Task 5):** Final verification + PR.

**Tech stack:** Adds two production deps:
- `androidx.navigation3:navigation3-runtime:1.1.1`
- `androidx.navigation3:navigation3-ui:1.1.1`

No serialization plugin, no Koin-nav3 helper, no adaptive-nav module. All three deferred to the phase that earns them.

**Branch:** `feature/phase2.2d-navigation3` (off `development` after 2.2c merged via PR #16).

**Constraints:**
- Behavior is observably identical pre- and post-phase. The calculator screen and all interactions look and feel the same.
- All 16 existing unit tests still pass at every checkpoint. Test count stays at 16.
- `applicationId`, namespace, `versionCode/Name`, theme, AGP version — all unchanged.
- Nav3 version `1.1.1` was verified at spec time against `https://dl.google.com/dl/android/maven2/androidx/navigation3/navigation3-runtime/maven-metadata.xml` (current stable; 1.2.0-alpha02 is prerelease).
- The instrumented `CalculatorScreenTest` continues to pass without modification.

**Pre-execution check:** Branch is `feature/phase2.2d-navigation3`, working tree is clean (modulo `.idea/` files), baseline `./gradlew :app:assembleDebug` and `./gradlew test` pass with 16 unit tests; file layout is the post-2.2c state.

## Task 3 — Create Routes.kt + NavRoot.kt

- [ ] Create `app/src/main/java/dev/gaddal/sifr/navigation/Routes.kt`:
  ```kotlin
  package dev.gaddal.sifr.navigation

  import androidx.navigation3.runtime.NavKey

  data object CalculatorRoute : NavKey
  ```

- [ ] Create `app/src/main/java/dev/gaddal/sifr/navigation/NavRoot.kt`:
  ```kotlin
  package dev.gaddal.sifr.navigation

  import androidx.compose.runtime.Composable
  import androidx.compose.runtime.remember
  import androidx.navigation3.runtime.NavBackStack
  import androidx.navigation3.runtime.NavKey
  import androidx.navigation3.runtime.entry
  import androidx.navigation3.runtime.entryProvider
  import androidx.navigation3.ui.NavDisplay
  import dev.gaddal.sifr.feature.calculator.ui.CalculatorRoot

  @Composable
  fun NavRoot() {
      val backStack = remember { NavBackStack<NavKey>(CalculatorRoute) }
      NavDisplay(
          backStack = backStack,
          onBack = { keysToRemove -> repeat(keysToRemove) { backStack.removeLastOrNull() } },
          entryProvider = entryProvider {
              entry<CalculatorRoute> { CalculatorRoot() }
          },
      )
  }
  ```

- [ ] Run `./gradlew :app:assembleDebug` — expected: BUILD SUCCESSFUL. `NavRoot` is unreferenced but compiles cleanly.
- [ ] `git add app/src/main/java/dev/gaddal/sifr/navigation/Routes.kt app/src/main/java/dev/gaddal/sifr/navigation/NavRoot.kt`
