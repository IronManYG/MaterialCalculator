# Phase 2.1 — Namespace Rename Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename Kotlin namespace from `com.example.materialcalculator` to `dev.gaddal.sifr`, rebrand user-visible app label to "Sifr" (EN) / "صفر" (AR), without touching `applicationId` or any behavior.

**Architecture:** Five-stage migration with atomic commits.
- **Stage A (Task 2):** Update `app/build.gradle.kts` namespace — safe-isolated change because nothing in Kotlin source references `R.*` (verified by grep at spec time).
- **Stage B (Tasks 3–6):** Per-source-set bulk moves. Each task: `git mv` directory tree + rewrite `package` declarations + rewrite cross-file `import` statements + verify the build at that source set's level. One source set per commit.
- **Stage C (Tasks 7–8):** Theme & resource renames — bundles the `MaterialCalculatorTheme` Kotlin function rename, the `Theme.MaterialCalculator` XML style rename, the manifest references, and the `app_name` strings (EN + new `values-ar/`).
- **Stage D (Task 9):** Project-level identifiers (`rootProject.name` in `settings.gradle.kts`).
- **Stage E (Tasks 10–12):** Docs update + final verification + PR.

**Tech stack:** No new tools. Same as Phase 2.0 baseline (Kotlin DSL, version catalog, Gradle 9.5.0, AGP 9.2.1, Kotlin 2.3.21, JDK 21 toolchain).

**Branch:** `feature/phase2.1-namespace-rename` (already cut off `development`; this branch already carries the brainstorm artifact `40160f0` and the spec `8d57d82`).

**Constraints:**
- `applicationId` MUST stay `com.gaddal.materialcalculator` — preserves the live Play Store listing from v1.2.0.
- `versionCode 5` / `versionName "1.2.0"` unchanged (no new release in this phase).
- Tests must continue to pass at every checkpoint (currently 12 unit tests pass).
- Each commit must build clean (no intermediate red states).
- Constants.kt source-set duplicates exist but are unreferenced — they move with their source set, no cleanup attempted in this phase.

**Pre-execution requirement:** Spec §2 collision-check checklist completed (Play Store search, App Store search, GitHub username check, trademark sanity check). If any returns a hard blocker on "Sifr", switch to fallback "Raqam" and `s/sifr/raqam/g` this plan before starting.
